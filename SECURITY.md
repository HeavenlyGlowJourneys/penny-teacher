# Security Policy

## Supported Versions

Security updates are provided for the latest version of Penny Teacher maintained in this repository.

Older versions may not receive security updates. Users should update to the latest available version whenever possible.

## Reporting a Vulnerability

If you discover a security vulnerability in Penny Teacher, please report it responsibly.

- Use GitHub's **Private vulnerability reporting** feature for this repository, where available.
- Do not disclose security vulnerabilities in public GitHub issues or discussions.
- Include a clear description of the vulnerability, the steps needed to reproduce it, and any potential impact.
- Please avoid accessing, sharing, or exposing real teacher, learner, parent, or school data when investigating or reporting a vulnerability.

We will review reports and aim to acknowledge them within five business days.

Please allow us reasonable time to investigate and address a reported vulnerability before making it public.

Thank you for helping keep Penny Teacher and its users safe.
